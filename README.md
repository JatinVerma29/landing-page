# 🇮🇳 Explore India — Travel Landing Page

A simple, responsive travel-themed landing page built with pure HTML and CSS. Created as a personal frontend practice project.

## 🌟 Features

- Fixed glassmorphism-style navbar with Home, Destinations, and Contact links
- Full-screen hero section with a background image
- Quick-action buttons — Tour Packages, Cultural Experiences, Travel Guide
- Informational section about the Taj Mahal
- Responsive design — stacks properly on mobile screens

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, media queries, inline styles)
- No frameworks or libraries — pure vanilla

## 📁 Project Structure

```
landing-page/
├── index.html   ← Main page
└── hero.jpg     ← Hero background image
```

## 🚀 How to Run

No setup needed. Just open `index.html` in any browser:

```bash
# Option 1 — double-click index.html in your file manager

# Option 2 — via terminal
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```
